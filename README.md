# B站稿件批量删除 · 内部服务

> by 小玲依 · maintained by [小花猫](https://github.com/xiaohuamao-labs)

B 站创作中心的「删除稿件」被人机验证（极验 v3）挡着，手动一条条点非常痛苦。
本项目是**内部服务**：纯协议、无浏览器，按账号批量删除稿件。

**不对外开放注册，也不提供公网调用。** 接入、定制、报价请联系文末渠道。

## 能力

| 项 | 说明 |
|---|---|
| 删除范围 | 自己账号下的稿件（需本人登录态） |
| 链路 | APP 接口优先，失败自动降级网页 + 验证码求解 |
| 速率 | 单条约 1~3 秒，按条节流 |
| 批量 | 多账号 / 数千条，断点续删 |

## 接入方式

- **自助/批量**：由内部 worker 执行，客户只需提供账号授权
- **定制**：多账号、定时任务、结果落库、失败清单导出

接口与自动化流程不公开；接入后按需提供。

## 收费

按条 / 按号 / 打包，失败不计费。删除每条会扣 2 硬币（B 站规则，客户承担）。
